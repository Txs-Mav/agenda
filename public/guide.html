Ton agenda de cégep,
rempli tout seul depuis Omnivox

Horaire, travaux, examens et MIO collectés chez toi, affichés dans un tableau de bord clair. Tes identifiants ne quittent jamais ta machine — chacun fait tourner sa propre copie.

Installer en 5 étapes Voir l'agenda Ma session a expiré

Comment ça marche

1 · Tu te connectes une fois

Fenêtre visible, tu tapes ton code de vérification toi-même. Le script ne le voit jamais.

2 · La session est réutilisée

Une collecte automatique passe toutes les heures, sans jamais se reconnecter.

3 · Ton agenda se remplit

Échéances datées avec compte à rebours, MIO résumés, pastilles sur les dates d'examen.

🔒Modèle de sécurité : aucun serveur central. Ton mot de passe vit dans un fichier .env chez toi, exclu de git. L'authentification multifacteur n'est jamais contournée — c'est toi qui saisis le code, le script attend.

Installation en une commande

Ouvre le Terminal (Cmd + Espace, tape « Terminal », Entrée), colle cette ligne, Entrée — et laisse-toi guider :

curl -fsSL https://agenda-five-sigma.vercel.app/install.sh | bash

Le script vérifie les outils, télécharge le programme, ouvre le fichier où toi seul écris tes identifiants, lance la connexion (tu tapes le code de vérification toi-même) et installe la collecte automatique. Les étapes ci-dessous sont la version manuelle, si tu préfères tout faire toi-même.

1 Prérequis

Un Mac (la collecte automatique utilise launchd), Node.js 20+ et git.

# vérifier :
node --version && git --version

2 Cloner et installer

git clone https://github.com/Txs-Mav/agenda.git
cd agenda
npm install
npx playwright install chromium

3 Tes identifiants — chez toi seulement

Copie le gabarit, puis remplace les deux REMPLACE_MOI par ton matricule et ton mot de passe Omnivox. Ce fichier est déjà dans .gitignore : il ne peut pas être commité ni envoyé où que ce soit.

cp .env.example .env
open -e .env
💡Tant que les valeurs d'exemple sont présentes, le programme refuse de tenter une connexion — impossible d'armer le captcha par accident.

4 La connexion, guidée

Une fenêtre s'ouvre, tes identifiants sont préremplis. Il ne reste que l'étape de vérification :

npm run login
📱Quand le code apparaît : saisis-le dans la fenêtre, puis coche « se souvenir de cet appareil » si l'option est proposée — c'est ce qui évite de refaire cette étape à chaque collecte. Le script attend jusqu'à 10 minutes, puis enregistre la session.
UNE SEULE FOIS · ENSUITE LA SESSION EST RÉUTILISÉE

5 Collecter, puis automatiser

Première collecte immédiate :

npm run scrape

Puis la collecte horaire automatique (une fois) :

cp horaire.scrape.plist ~/Library/LaunchAgents/ca.qc.cegeptr.agenda.scrape.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/ca.qc.cegeptr.agenda.scrape.plist

Et pour voir ton tableau de bord avec tes données :

cd public && python3 -m http.server 8899
# puis ouvre http://localhost:8899

Ton horaire par capture d'écran

Pas besoin de saisir ton horaire à la main : photographie-le, l'agent le lit et remplit la grille.

1 · Prendre la capture (Mac) — ouvre ton horaire dans Omnivox (Léa → Horaire), puis appuie sur Cmd + Maj + 4 et trace un rectangle qui couvre toute la grille, colonne des heures comprise — sans elle, l'agent refuse de deviner. Le fichier apparaît sur le Bureau (« Capture d'écran … .png »). Une photo d'iPhone fonctionne aussi (HEIC converti automatiquement).

2 · La donner à l'agent — dans le Terminal, tape la commande avec une espace à la fin, puis glisse le fichier dans la fenêtre et appuie sur Entrée :

cd ~/AgendaCegep
npm run horaire (glisse l'image ici)

L'agent lit la grille (claude-opus-5, une image, quelques cents), l'enregistre, et si ton compte nuagique est configuré, la pousse dans la base — ton tableau de bord l'affiche partout où tu te connectes.

👁️Vérifie le résultat : la commande liste chaque cours extrait. Un bloc absent ou décalé = reprends une capture plus nette, colonne des heures bien visible.

Facultatif · Synchroniser vers le nuage

Pour retrouver tes échéances et MIO depuis n'importe où : crée un compte d'agenda (bouton « Connexion » dans la barre latérale de l'app), confirme le courriel reçu, puis donne ces deux variables à ton agent local :

AGENDA_EMAIL=toi@exemple.com
AGENDA_PASSWORD=ton-mot-de-passe-d-agenda
🔒Ce compte ne transporte que les données dérivées (échéances, résumés). Tes identifiants Omnivox n'y sont jamais — ils restent dans ton .env local. Côté base, chaque compte ne peut lire que ses propres lignes.

Quand la session Omnivox se déconnecte

Omnivox finit toujours par fermer la session : après quelques jours, après un changement de mot de passe, ou si tu te déconnectes depuis un autre appareil. La collecte automatique ne se reconnecte jamais toute seule — elle s'arrête net et te rend la main. C'est voulu : une tâche de fond qui réessaie une connexion arme le captcha d'Omnivox, puis verrouille ton dossier.

🔔Tu n'as rien à surveiller. Dès qu'un passage horaire échoue, une notification macOS te le dit, avec la commande exacte à taper. Elle revient au plus une fois toutes les 6 h tant que la panne dure — pas 24 fois par jour — et une dernière t'annonce que la collecte est rétablie.

1 · Reconnaître le symptôme — ton agenda ne bouge plus depuis quelques heures. Le journal le dit franchement :

cd ~/AgendaCegep
tail -20 data/scrape.log
🔎Tu cherches ces deux lignes : ✖ Aucune session valide, puis ARRÊT DÉFINITIF — aucun réessai automatique. C'est ce cas-ci. Un doute ? npm run check tranche en dix secondes : « session réutilisée » = tout va bien, rien à faire.

2 · Refaire la session — et rien d'autre — deux commandes, dans l'ordre :

npm run login    # fenêtre visible : tu saisis le code de vérification
npm run scrape   # rattrape tout de suite la collecte manquée
📱Comme au premier jour : tes identifiants sont préremplis, le code de vérification s'affiche, tu le tapes dans la fenêtre. Coche « se souvenir de cet appareil » si l'option revient — c'est ce qui espace les reconnexions.
✅Il n'y a rien à réinstaller. Ne relance pas install.sh, ni npm install, ni npx playwright install, ni la tâche launchctl : tout ça est déjà en place et le reste. Seule la session avait expiré. La collecte horaire repart d'elle-même à la prochaine heure — le npm run scrape ci-dessus sert seulement à ne pas attendre.
LA SESSION SEULEMENT · L'INSTALLATION RESTE INTACTE

3 · Si la connexion résiste — laisse tomber le préremplissage et fais tout à la main dans la fenêtre :

npm run login -- --manuel
⛔Une seule tentative à la fois. Si le login échoue, ne relance pas la commande en boucle : des essais répétés arment le captcha d'Omnivox, puis verrouillent ton dossier étudiant. Attends quelques minutes, connecte-toi d'abord à la main sur omnivox.ca dans ton navigateur habituel pour confirmer que ton compte va bien, et reviens ensuite à npm run login.

En cas de pépin

« Aucune session valide »

La session a expiré : npm run login puis npm run scrape. La marche à suivre complète est juste au-dessus.

Captcha au login

Ferme, attends quelques minutes, puis npm run login -- --manuel et connecte-toi entièrement à la main dans la fenêtre. Jamais deux essais de suite.

Rien ne se collecte

Regarde data/scrape.log. « session réutilisée » suivi de comptes = tout va bien ; « ARRÊT DÉFINITIF » = refais le login.

La tâche horaire ne passe plus — vérifie qu'elle existe encore, et relance-la sans attendre l'heure :

launchctl print gui/$(id -u)/ca.qc.cegeptr.agenda.scrape
# « state = not running » entre deux passages, c'est normal
launchctl kickstart -k gui/$(id -u)/ca.qc.cegeptr.agenda.scrape

Aucune notification n'arrive — vérifie que le mécanisme fonctionne chez toi :

osascript -e 'display notification "test" with title "Agenda Cégep"'

Rien à l'écran ? macOS bloque les notifications de Script Editor. Ouvre Réglages Système → Notifications → Script Editor et autorise-les. L'état de la collecte reste de toute façon lisible dans data/health.json.

Seul « Could not find service » veut dire que la tâche horaire a disparu. C'est alors la seule pièce à réinstaller — le reste du programme est intact :

launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/ca.qc.cegeptr.agenda.scrape.plist
