Variantes

Si ton cas est différent.

  • Pas envie d’attendre l’heure ? npm run moodle lance un passage immédiat, n’importe quand.
  • Tu as un compte local Moodle (nom d’utilisateur + mot de passe, sans M365) ? Écris-le dans .env (MOODLE_USER et MOODLE_PASS) : le jeton s’obtient sans fenêtre, sans navigateur, sans geste du tout.
  • Le jeton finit par mourir (rare — il vit des mois) ? npm run moodle-login -- --force, même connexion d’habitude, reparti.
  • Autre cégep sur la plateforme DECclic ? Change MOODLE_HOST dans .env — tout le reste est identique.

Charte

Le même contrat que pour Omnivox.

  • Ton mot de passe M365 n’existe pas ici. Tu le tapes sur la page de Microsoft, dans une fenêtre que le script regarde sans toucher. Ce qui revient, c’est un jeton de lecture — pas tes identifiants.
  • Le jeton vit chez toi. Dans data/, exclu du dépôt, jamais commité, jamais envoyé à un serveur tiers. Le supprimer = débrancher Moodle, immédiatement.
  • Jamais de connexion automatisée. Le flux utilisé est celui, officiel, de l’app mobile Moodle. Pas de formulaire rejoué, pas de réessai, pas de contournement.
  • Lecture seule, dérivé seul. La collecte lit tes cours ; elle n’écrit rien sur Moodle. Et comme pour Léa, seul le dérivé — échéances, titres, liens — rejoint le compte nuagique facultatif.
